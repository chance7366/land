# LandChance A4 광고전단지 자동 생성 — 개발 지침서

> 상태: **P0/P1 운영 적용** (미리보기·인쇄 / Playwright PDF 서버저장은 후속)  
> 관련 목업: `/mockup/a4-flyer`, `/mockup/a4-flyer/admin-ux`  
> 운영: 매물·경매 **수정** 화면 sticky 「광고전단지」·경매 리포트 섹션 FLYER 카드  
> 기준일: 2026-07-27

---

## 1. 목적

관리자 **매물 등록/수정**·**경매물건 자동등록/수정**에서 저장된 데이터를 바탕으로  
**A4 세로 1페이지(210×297mm)** 광고 전단지를 미리보기·PDF·인쇄한다.

---

## 2. 범위 (Phase)

| Phase | 내용 | 비고 |
|-------|------|------|
| P0 | 매물(매매·전/월세) HTML 미리보기 + Playwright PDF | |
| P1 | 경매 전단지 (`rightsAnalysis` 요약·사진) | |
| P2 | Gemini로 헤드라인·Insight만 보조 | 법정 표/푸터는 코드 고정 |
| 제외(v1) | `@react-pdf`, 계약 3일 자동 광고삭제, Unifine 다크 인쇄, 중개보조원 표기 | |

---

## 3. 페이지 여백 (확정)

기준 초안 패딩 `8mm`(상하) · `9mm`(좌우) 대비 사용자 조정:

| 방향 | 배수 | 확정 값 |
|------|------|---------|
| 위(top) | ×2 | **16mm** |
| 좌·우 | ×1.5 | **13.5mm** |
| 아래(bottom) | ×1.5 | **12mm** |

CSS 예: `padding: 16mm 13.5mm 12mm;`  
`@page { size: A4 portrait; margin: 0; }` + 시트 내부 패딩으로 여백 확보.

---

## 4. 레이아웃 순서 (확정 · 겹침 금지)

상단 → 하단 **단일 세로 흐름**. 절대 배치로 사진·표가 겹치면 안 된다.

1. **Header** — 유형 뱃지, 헤드라인, 가격/최저가, QR  
2. **Photos** — **1행 × 3장, 정사각형(`aspect-ratio: 1`)**, `object-cover`  
   - 사진 0~2장이면 빈 칸은 플레이스홀더  
   - 4장 이상이면 **앞 3장만** 사용  
3. **핵심 정보(Spec table)** — 사진 **아래**에만 배치 (2열 key-value)  
4. **Insight** (영역 높이는 짧게 유지 가능)  
   - 매물: **특장점 · 입지**  
   - 경매: **전문가 포인트**  
5. **Footer** — 법정 고지 · **2열 배치**로 가로 공간 활용 (우측 여백 낭비 금지). 면책 문구는 하단 전폭.

비율(15/30/…)은 가이드일 뿐이며, **1페이지 초과 시** 사진 한 변 길이·Insight 줄 수를 줄인다 (본문 글자는 축소 최소화).

---

## 5. 디자인 · 타이포 (시니어 가독성)

주요 독자층이 **중장년·시니어**이므로 본문 포인트는 크게 잡는다.

| 요소 | 기준 (대략) | 비고 |
|------|-------------|------|
| 유형 뱃지 (매매 / 법원 경매) | **기존 대비 ×2** (약 18px) | 최우선 시인성 |
| 헤드라인 · 가격 | 약 16~18px / 15~16px | 굵게 |
| 핵심 정보 표 | 라벨·값 **약 12~13px** | 표 제목 ~14px |
| 특장점·입지 / 전문가 포인트 | 제목 ~14px, 본문 **약 12~13px** | **영역 높이는 짧게** OK |
| Footer 법정 고지 | **약 8px 유지** | **2열**로 배치해 우측 공백 줄임 |

- **웹 관리자 UI**: Unifine 다크 글래스 유지  
- **전단지 본문**: 라이트 인쇄 전용 (기존 경매 export/리포트와 동일 계열)  
- 유형 액센트(print only):  
  - 매매 `#1E3A8A` / `#EA580C`  
  - 임대 `#065F46` / `#0D9488`  
  - 경매 `#0F172A` / `#D97706`

---

## 6. 데이터 · URL

- 매물: Property + `specs` (사용승인일, 위반건축물, 관리비 세부 등)  
- 경매: Auction + `rightsAnalysis` 요약(길이 클램프)  
- 사무소: `src/lib/office-profile.ts` 단일 소스 (`bidAgentRegNo` 추후 추가)  
- QR / 상세 링크:  
  - 매물 `/properties/{id}`  
  - 경매 `/auctions/{id}`  
  - 호스트는 `APP_BASE_URL` 등 사이트 base (하드코딩 `landchance…` 지양)

---

## 7. 검증 정책 (v1)

- Soft gate: 누락 필드 목록 + 「법정 미비」 배지, 미리보기는 가능  
- 정식 PDF는 필수 세트 충족 시 (필수 세트는 구현 직전 필드표로 확정)  
- 계약 3일 광고 삭제: **운영 정책으로만** 기록, 자동화는 후속

## 8. UX — 버튼 위치 · 결과 보기 (운영 적용 시)

### 8.1 매물 등록 (`PropertyForm`)

- **위치 A (권장):** 하단 sticky 바 — `등록 저장` **왼쪽**에  
  `광고전단지 생성` (신규 등록 직후·미저장 시 disabled, **수정 모드·저장 완료 후** 활성)  
- **위치 B:** 저장 성공 토스트/배너에 `전단지 만들기` 링크  
- 생성 결과는 모달 또는 `/admin/properties/[id]/flyer` 미리보기

### 8.2 경매 자동등록 (`AuctionForm`)

- **위치 A (권장):** 수정 화면의 리포트 섹션에 **「A4 광고전단지」** 카드  
  (일반리포트·회원리포트와 동일 패턴: 생성 / 보기)  
- **위치 B:** 하단 sticky — `등록 저장` 옆 `광고전단지` (저장 후 활성)  
- Gemini 풀 리포트와 **별도** 산출물 (짧은 1페이지 전단)

### 8.3 생성된 전단지 보기

1. 생성 클릭 → 미리보기(라이트 A4)  
2. **PDF 다운로드** (Playwright, 기존 `auction-report-pdf` 패턴)  
3. **인쇄** (`window.print` 또는 PDF 인쇄)  
4. 재생성 시 최신 데이터로 덮어쓰기 (URL 필드 선택: `flyerUrl` 등 — 스키마는 구현 시)

목업 참고: `/mockup/a4-flyer/admin-ux`

## 9. 기술 표준 (구현 시)

- 컴포넌트: `FlyerSheet` + 관리자 트리거 (목업이 아닌 운영 코드)  
- PDF: Playwright `format: "A4"`  
- QR: 패키지 또는 서버 생성 data-URL  
- API 예: `POST /api/admin/properties/[id]/flyer`, `…/auctions/[id]/flyer`

---

## 10. Gemini 역할

- 입력: 등록 필드 + (경매) 기존 분석 텍스트  
- 출력: 헤드라인 1줄, 서브 불릿, Insight 80~120자  
- **금지:** 법정 스펙 표·푸터·가격 숫자 임의 변경

---

## 11. Cursor 작업 시

- 전단지 PDF에 Unifine 다크 강제 금지  
- 사무소 정보는 `office-profile`만 사용  
- 운영 연결: `FlyerSheet` · `FlyerPreviewModal` · `PropertyForm` / `AuctionForm`  
- PDF 서버 저장 API는 후속 (현재는 브라우저 인쇄→PDF 저장)
