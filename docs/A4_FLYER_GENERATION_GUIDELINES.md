# Part II — 창문전단지 (창부착용) ★ 운영 적용

> 상태: **운영 적용** · 관리자 sticky 「창문전단지」 · Type A/B/C 미리보기 선택  
> 레퍼런스 목업: `/mockup/window-flyer`  
> 코드: `WindowFlyerSheet.tsx` · `WindowFlyerPreviewModal.tsx` · `map-property-window.ts` · `map-auction-window.ts`

## II-1. 목적 · 핵심 원칙

사무실 창문에 부착하여, 지나가는 고객이 **걸으면서 2~3초 안에** 거래유형·가격·위치를 직관적으로 파악하게 한다.

1. **시인성 + 감성** — 큰 사진, 컬러 블록, 세리프/극후 고딕. **글자가 작아지면 실패.**  
2. **아이콘화** — 방·욕실·면적·주차 = 픽토그램 + 짧은 단어.  
3. **템플릿 다변화** — Type A/B/C. 기본 추천: 매매→A, 월세/전세→B, 경매→C. 미리보기에서 변경 가능.  
4. **Footer 완전 채움** — QR·상호·대표·등록번호·전화·주소. 비우지 않음.

## II-2. 템플릿 3종

### Type A — 모던 갤러리 (OPEN HOUSE · 노란 가격 원)

- 상단 초대형 헤드라인 + 체크 특징 2개  
- 집 지붕형 크롭 사진 + **머스터드 원형**에 가격(또는 경매 할인율)  
- 위치 한 줄 + Footer

### Type B — 컬러 블록 (JUST LISTED · 틸+머스터드)

- 상단 사진 + 오버랩 틸/머스터드 블록에 유형·**초대형 가격**  
- FEATURES 불릿 또는 경매 할인율 블록  
- 스펙 아이콘 그리드 + Footer

### Type C — 클린 카드 · 리스트

- 상단 사무소 바 또는 `매매`/`경매` 초대형 레드 헤드  
- 사진 2장 + 점선 리더 가격 카드  
- 경매: 감정가(취소선) → 최저가 + **할인율 %**

## II-3. 타이포 · 보행 시인성 (필수)

| 역할 | 최소 권장 | 비고 |
|------|-----------|------|
| 거래유형 | **48~72px**급 | 1순위 |
| 가격 · 할인율(%) | **40~64px**급 | 1순위 |
| 위치·단지명 | **20~32px** | 2순위 |
| 스펙·불릿 | **16~22px** | 아이콘 동반 |
| Footer 전화 | **24~28px** | 상호보다 크게 |
| Footer 상호·등록 | 12~15px | 신뢰용 |
| 보조 라벨 | 12px 이상 | 남발 금지 |

**규칙: 정보가 많으면 글자를 줄이지 말고 항목 수를 줄인다.**

팔레트 택 1: 웜(아이보리+머스터드) / 쿨(틸·네이비) / 신뢰(그레이+레드 유형·가격)

## II-4. Footer — 무엇을 채우는가

하단 **약 10~14%** = 고정 신뢰 구역 (솔리드 컬러 바).

| 필수 | 소스 · fallback |
|------|-----------------|
| QR | `/properties/{id}` · `/auctions/{id}` |
| 상호 | `OFFICE_PROFILE.name` |
| 대표 · 등록번호 | `brokerName` · `regNo` |
| 전화 (최대) | `agentPhone` \|\| `brokerPhone` |
| 주소 | `addressShort` |

넣지 않음: 긴 법정 고지·권리분석 장문 (광고전단지 전용).

## II-5. UX

- 매물/경매 **수정** sticky · 경매 리포트 카드: 「창문전단지」  
- 모달에서 **Type A / B / C** 탭 전환 후 **인쇄/PDF** 또는 **PPT 다운로드**  
- PPT: `pptxgenjs` · A4 세로 1장 · 선택 Type 기준 (`window-flyer-pptx.ts`)  
  - 창 부착·인쇄 품질은 HTML 인쇄(PDF) 권장, PPT는 편집·재사용용  
- 신규 미저장 시 disabled  
- 광고전단지와 컴포넌트·매핑 **분리**

## II-6. Gemini (후속)

- Type 추천 + 불릿 3개 + 헤드라인  
- 경매 **할인율 %** 코드가 계산 (AI가 가격 임의 변경 금지)  
- 출력은 Type A/B/C JSON 카피 세트
